# Prompt Engineering Assignment – Part 2

## Project Overview

This project demonstrates the use of AI-assisted programming tools for debugging Python code, generating unit tests, and improving code quality.

## Features

- Debugging Python functions using AI assistance.
- Calculating the average of a list of numbers.
- Finding the maximum value in a list.
- Counting even numbers in a list.
- Testing functions using Python's built-in unittest framework.

## Files

- `debug_task.py` – Contains the corrected Python functions.
- `test_debug_task.py` – Contains unit tests for the functions.
- `README.md` – Documents the project and instructions.

## Requirements

- Python 3
- No external Python packages are required.

## Running the Program

Run the unit tests from the project directory:

```bash
python -m unittest -v
```

## Testing

The test suite covers average calculation, maximum-value detection, and even-number counting, including selected edge cases.

## Learning Outcomes

This project demonstrates how AI can assist with debugging, test generation, code review, and documentation. All suggested changes should be reviewed and tested before being accepted.
